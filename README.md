## Compose App featuring a Simple Interactive Gallery

### What about it?

* It's a rather simple android application featuring a gallery where you interact with it using buttons.
* The gallery loops forwards and backwards and two switches decide what happens.
* The state is lifted aka hoisted from both the `Image` and `Text` (Title & Description) composables.
* The ancestor keeps the states.
